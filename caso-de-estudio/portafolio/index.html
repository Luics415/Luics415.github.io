Un portafolio diseñado para una conversación técnica

Esta versión transforma una galería de nueve tarjetas en un sistema de presentación profesional: trece repositorios Stars, fichas con profundidad técnica, evidencia visual verificable y una jerarquía pensada para reclutadores y desarrolladores.

Arquitectura

Índice ligero

La portada carga metadatos breves, filtros y enlaces de los 13 repositorios destacados sin transportar los ejemplos técnicos completos.

Contenido por ruta

Cada ficha resuelve arquitectura, flujo, decisiones y compromisos mediante un perfil desacoplado; un segundo mapa aporta código real o conceptual con procedencia individual.

Salida estática

TanStack Router y Vite prerenderizan la portada y las rutas para servirlas desde GitHub Pages sin backend ni cuentas.

Decisiones de ingeniería

  • Separar los 13 Stars, los tres experimentos históricos y este caso de estudio evita que todos compitan con el mismo peso visual.
  • Las capturas reales se conservan como evidencia; cuando no existen, una portada editorial se identifica explícitamente como tal.
  • Cada fragmento distingue código real de GitHub, fuente de trabajo, patrón representativo o base externa; los ejemplos conceptuales nunca se atribuyen como extractos literales.
  • Los filtros usan botones accesibles, búsqueda tolerante a tildes y un estado inicial que deja visibles todos los enlaces durante el prerenderizado.
  • La animación ambiental respeta movimiento reducido y el menú mantiene navegación por secciones en pantallas pequeñas.

Compromisos

Una salida completamente estática reduce operación y superficie de ataque, pero no ofrece edición en línea. La fuente sigue siendo necesaria para regenerar rutas y recursos; el repositorio público conserva el artefacto listo para GitHub Pages.

La profundidad técnica aumenta el contenido de cada ficha, por lo que los datos extensos se cargan fuera del índice principal y las listas largas usan renderizado diferido del navegador.

Relaciones por familia y categoría

export function getRelatedProjects(project: Project, limit = 3) {
  return projects
    .filter((candidate) => candidate.slug !== project.slug)
    .map((candidate) => ({
      candidate,
      score:
        (candidate.family === project.family ? 6 : 0) +
        (candidate.category === project.category ? 3 : 0),
    }))
    .sort((a, b) => b.score - a.score)
    .slice(0, limit)
    .map(({ candidate }) => candidate);
}

Este fragmento procede de la fuente editable local. El repositorio de GitHub Pages publica por ahora el artefacto compilado, por lo que todavía no existe un enlace público inmutable para este archivo TypeScript.

Publicación continua con GitHub Pages

YAML

El flujo usa el pipeline oficial de Pages, permisos declarados y un artefacto estático; el despliegue no depende de credenciales manuales almacenadas en el proyecto.

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout published site
        uses: actions/checkout@v4
      - name: Configure Pages
        uses: actions/configure-pages@v5
      - name: Upload static site
        uses: actions/upload-pages-artifact@v3
        with:
          path: .
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
