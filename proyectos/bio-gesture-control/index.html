Decisiones Fundamentales

Por qué se diseñó de esta manera

  • 1Separar observación e intención evita que ruido visual dispare directamente acciones del sistema.
  • 2Aplicar una ventana corta de suavizado equilibra estabilidad y latencia.
  • 3Centralizar umbrales facilita calibrar distintos tamaños de mano, cámaras y distancias.

Trade-Offs Asumidos

Compromisos de ingeniería

  • Más suavizado reduce falsos positivos, pero hace que el cursor responda con mayor retraso.
  • Una resolución alta mejora detalle, aunque eleva uso de CPU y temperatura.
  • Reglas geométricas son explicables y rápidas, pero menos flexibles ante posturas ambiguas.

Sección 1

El proyecto

Bio-Gesture Control Pro convierte la webcam en una interfaz de control sin contacto. Detecta la mano, interpreta el gesto y lo traduce en acciones del sistema operativo.

Sección 2

Cómo funciona

MediaPipe extrae los puntos clave de la mano cuadro a cuadro. Una capa de lógica clasifica la postura de los dedos en gestos, aplica suavizado para evitar falsos positivos y entrega acciones a los adaptadores de entrada y audio de Windows.

Sección 3

Instalación

Requiere Python 3.10+. Instala las dependencias con pip install -r requirements.txt y ejecuta el script principal. La calibración inicial toma unos segundos.

from collections import deque

history = deque(maxlen=5)

def stable_point(x: float, y: float) -> tuple[float, float]:
    history.append((x, y))
    count = len(history)
    mean_x = sum(point[0] for point in history) / count
    mean_y = sum(point[1] for point in history) / count

    return mean_x, mean_y
