Dev Visualizer

Atlas visual animado para estudiar desarrollo de software, desde fundamentos hasta producción.

Ver código

El proyecto

Dev Visualizer es un atlas educativo que ayuda a comprender qué ocurre dentro de un sistema. Combina explicaciones breves, código, movimiento y conclusiones visuales para construir modelos mentales claros.

Arquitectura visual

El contenido vive separado de la presentación. Las colecciones comparten componentes y un motor selecciona metáforas visuales —como pipelines, árboles, colas, estados y trazas— según el significado de cada concepto.

Calidad y publicación

Está construido con Next.js, React y TypeScript estricto. Incluye validación automática, diseño responsive, soporte para movimiento reducido y un flujo de publicación estática mediante GitHub Actions.

Puntos destacados

  • 17 colecciones, 34 rutas y más de 2,200 conceptos técnicos
  • 28 familias visuales reutilizables con animaciones autónomas
  • Exportación estática, accesibilidad y despliegue automatizado en GitHub Pages
