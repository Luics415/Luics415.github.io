Credit Card Animation UI

Interfaz interactiva de tarjeta con giro 3D en CVV, resaltado dinámico y detección de marca BIN.

Revisar repositorio

El proyecto

Credit Card Animation UI traslada la experiencia táctil de una tarjeta física al formulario web. Los datos introducidos se proyectan en directo sobre la superficie de la tarjeta, reduciendo la tasa de errores de tipeo y elevando la confianza del usuario en flujos de checkout.

Arquitectura visual

Construida exclusivamente con HTML5 semántico, CSS3 moderno y JavaScript vanilla sin frameworks pesados. Las transformaciones 3D se ejecutan en la GPU para garantizar 60 FPS estables incluso en teléfonos móviles económicos.

Microinteracciones

Un indicador dinámico resalta con precisión el área de la tarjeta correspondiente al input activo. Cuando el usuario pasa al CVV, la tarjeta efectúa un volteo tridimensional suave para mostrar la banda magnética y la firma de seguridad.

Puntos destacados

  • Animación de giro de 180° en el eje Y mediante CSS 3D backface-visibility acelerado por GPU
  • Detección instantánea de franquicia (Visa, Mastercard, etc.) mediante expresiones regulares BIN
  • Mascara interactiva de enfoque que sigue la posición y dimensión del campo activo
  • Formateo automático de espacios y enmascaramiento seguro del código de seguridad

Arquitectura técnica

Una interfaz pequeña puede mantener estado, reglas y renderizado en módulos conceptuales aun sin framework. Los eventos producen acciones, un reductor calcula el siguiente estado y una función de presentación actualiza únicamente la parte necesaria del DOM.

Flujo de ejecución

  • Un control del navegador emite una acción con datos mínimos.
  • La lógica calcula un nuevo estado sin modificar directamente la interfaz.
  • El renderizado refleja el resultado y ofrece retroalimentación inmediata al usuario.

Decisiones de ingeniería

  • Conservar una única fuente de estado evita que texto, marcador y controles se contradigan.
  • Usar funciones puras vuelve predecibles las reglas incluso sin una biblioteca de componentes.
  • Delegar eventos reduce escuchas repetidas cuando la interfaz genera elementos dinámicos.

Compromisos y límites

  • JavaScript directo ofrece una carga pequeña, pero requiere disciplina manual al crecer la interfaz.
  • Actualizar solo nodos necesarios mejora rendimiento, aunque aumenta lógica de sincronización.
  • El estado en memoria es sencillo, pero se pierde al recargar salvo que se añada persistencia explícita.

Detección instantánea de franquicia por prefijos BIN

JavaScript

Evalúa los primeros dígitos de la tarjeta para identificar en tiempo real la marca bancaria y adaptar logotipos y fondos.

Procedencia: Código real del repositorio · script.js, líneas 30–50.

function detectCardInfo(number) {
  if (number.length === 0) return { brand: 'default', type: 'CreditCard' };

  // Limpiamos los espacios en blanco
  const num = number.replace(/\s/g, '');

  // Identificadores de red bancaria (BIN)
  if (/^4/.test(num)) return { brand: 'visa', type: 'VISA' };
  if (/^5[1-5]/.test(num)) return { brand: 'mastercard', type: 'MASTERCARD' };
  if (/^3[47]/.test(num)) return { brand: 'amex', type: 'AMERICAN EXPRESS' };
  if (/^6(?:011|5)/.test(num)) return { brand: 'discover', type: 'DISCOVER' };

  return { brand: 'default', type: 'CreditCard' };
}

Patrón técnico relacionado: Reductor mínimo para una interacción web

JavaScript

Ejemplo conceptual de reglas separadas del DOM para mantener predecible una miniaplicación.

Procedencia del ejemplo: Código representativo. Reconstrucción conceptual basada en el objetivo y stack públicos del proyecto; no es un extracto literal del repositorio.

const initialState = { score: 0, rounds: 0 };

export function reduce(state = initialState, action) {
  if (action.type === "win") {
    return { score: state.score + 1, rounds: state.rounds + 1 };
  }
  if (action.type === "loss") {
    return { ...state, rounds: state.rounds + 1 };
  }

  return state;
}
