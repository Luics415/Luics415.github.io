Del reporte ciudadano
al despacho prioritario.

Tlalne-Priority modela un flujo académico de atención urbana. Registra incidencias, calcula su urgencia, conserva las finalizadas y permite consultar cada cambio sin presentarse como un sistema oficial del Ayuntamiento.

03ARQUITECTURA & DECISIONES

Estructuras híbridas,
eficiencia algorítmica estricta.

El dominio se divide en modelos, servicios, repositorios y una interfaz de consola. Una cola de prioridad atiende el orden operativo, un índice por clave acelera consultas directas y la persistencia conserva registros e historial como conjuntos separados.

Doble Indexación: Heap O(log N) + Hash O(1)

El motor combina un Max-Heap para despachar de inmediato la emergencia más crítica con una tabla Hash para recuperar expedientes municipales por folio en tiempo constante.

Decisiones de diseño

  • Combinar cola de prioridad e índice evita recorrer toda la colección para las dos consultas principales.

  • Recalcular puntuaciones dependientes del tiempo impide ordenar con valores envejecidos.

  • Aislar CSV detrás de repositorios evita contaminar las reglas de negocio con serialización.

Compromisos asumidos

  • Mantener dos estructuras mejora consultas, pero obliga a sincronizarlas después de cada edición.

  • CSV es portable y auditable, aunque ofrece menos garantías transaccionales que una base de datos.

  • Una fórmula explícita es fácil de explicar, pero necesita calibración para no favorecer un único factor.
