QR Voxel Studio

Convierte códigos QR en jardines voxel 3D estacionales, explorables, exportables y compartibles.

Revisar repositorioAbrir demo

El proyecto

QR Voxel Studio convierte la estructura binaria de un código QR en un jardín 3D explorable. Cada módulo activo alimenta la composición voxel; el visitante puede recorrer el bosque, cambiar entre Primavera, Verano, Otoño e Invierno y regresar a una representación cenital fiel de la matriz.

Implementación

La aplicación utiliza Next.js 16, React 19, TypeScript, Three.js y React Three Fiber. jsQR decodifica la imagen normalizada y la librería qrcode reconstruye una matriz consistente a partir del contenido. El renderer interpola árboles, capas de follaje y módulos mediante InstancedMesh para reducir llamadas de dibujo.

Arquitectura y flujo de datos

El código separa carga, normalización, decodificación, reconstrucción, estado QRSlot, visualización, exportación y uso compartido. Esa frontera permite que el archivo original permanezca en el dispositivo y que la escena 3D reciba una matriz simple, independiente del formato de entrada.

Rendimiento, privacidad y publicación

La calidad del renderer se adapta al dispositivo y limita la frecuencia de las actualizaciones 3D más costosas. Los enlaces compartidos empaquetan la matriz por bits y no incluyen la imagen original. El proyecto se exporta como sitio estático y se publica automáticamente en GitHub Pages.

Puntos destacados

  • Pipeline local: normalización, decodificación, reconstrucción matricial y renderizado 3D
  • Bosque voxel con cuatro estaciones y transición hacia una vista cenital QR precisa
  • Enlaces compactos y exportación desde el navegador como PNG, video o GIF

Arquitectura técnica

Una aplicación estática ejecuta todo el pipeline en el navegador: normaliza la imagen, decodifica el contenido, reconstruye una matriz binaria y la entrega a un renderer WebGL desacoplado. El estado QRSlot conecta procesamiento, perfil estacional, exportación y enlaces compartidos sin depender de una API o base de datos.

Flujo de ejecución

  • El archivo se valida y normaliza en un canvas antes de intentar la lectura con jsQR.
  • El contenido decodificado se reconstruye como una matriz QR y se almacena junto con su perfil visual.
  • React Three Fiber convierte los módulos activos en instancias voxel y permite interpolar entre bosque y matriz cenital.
  • La exportación captura el canvas; el enlace compartido serializa una versión compacta de la matriz y la estación.

Decisiones de ingeniería

  • Reconstruir la matriz desde el contenido desacopla el renderer de los píxeles y del formato del archivo original.
  • Usar InstancedMesh reduce el costo de representar muchas piezas repetidas de troncos, hojas y módulos.
  • Versionar y empaquetar la matriz por bits mantiene los enlaces reproducibles sin subir la imagen a un servidor.

Compromisos y límites

  • El procesamiento local mejora privacidad y elimina infraestructura, pero traslada decodificación y exportación al dispositivo.
  • WebGL ofrece profundidad y animación, aunque necesita niveles de calidad y límites de frecuencia para móviles modestos.
  • Regenerar la matriz desde el contenido preserva el QR funcional, pero no reproduce defectos, logotipos o estilización del archivo original.

Decodificación local tolerante a inversión

TypeScript · jsQR

Normaliza el archivo, prueba orientaciones de contraste opuestas y devuelve un contrato explícito con contenido y dimensiones; un fallo produce un mensaje accionable para el usuario.

Procedencia: Código real del repositorio · commit 1fedc2a · src/features/qr-engine/decode-qr.ts, líneas 11–29.

export async function decodeQRFromFile(file: File): Promise<DecodedQR> {
  const { imageData, width, height } = await normalizeImageFile(file);

  const result = jsQR(imageData.data, width, height, {
    inversionAttempts: "attemptBoth",
  });

  if (!result) {
    throw new Error(
      "No pude detectar un QR válido en la imagen. " +
      "Prueba con una imagen más nítida, frontal y con margen blanco alrededor.",
    );
  }

  return {
    data: result.data,
    binaryData: Array.from(result.binaryData),
    sourceWidth: width,
    sourceHeight: height,
  };
}

Matriz compartible empaquetada por bits

TypeScript

Comprime cada módulo del QR en un bit y convierte el resultado a Base64 URL-safe, evitando incluir el archivo original en el enlace compartido.

Procedencia: Código real del repositorio · commit 1fedc2a · src/features/share/share-payload.ts, líneas 51–68.

function packMatrix(matrix: QRMatrix) {
  const size = matrix.length;
  const totalBits = size * size;
  const bytes = new Uint8Array(Math.ceil(totalBits / 8));
  let bitIndex = 0;

  for (let row = 0; row < size; row += 1) {
    for (let col = 0; col < size; col += 1) {
      if (matrix[row]?.[col]) {
        const byteIndex = Math.floor(bitIndex / 8);
        const shift = 7 - (bitIndex % 8);
        bytes[byteIndex] |= 1 << shift;
      }
      bitIndex += 1;
    }
  }

  return bytesToBase64Url(bytes);
}
