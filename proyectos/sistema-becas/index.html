Sistema de Becas

Plataforma PHP/MVC para gestionar convocatorias, solicitudes y validación documental.

Ver código

El proyecto

Sistema de Becas digitaliza el proceso de solicitud de becas de una institución educativa: desde la publicación de la convocatoria hasta la resolución final de cada expediente.

Arquitectura

Construido con PHP siguiendo el patrón MVC: controladores por módulo, modelos con acceso a MySQL y vistas reutilizables. La autenticación y los permisos se resuelven por rol en cada controlador.

Módulos principales

Gestión de convocatorias, registro y seguimiento de solicitudes, validación documental con historial de estatus, y administración de usuarios y permisos.

Puntos destacados

  • Roles diferenciados: alumno, revisor y administrador
  • Carga y validación de documentos por solicitud
  • Ciclo completo de convocatoria: publicación, solicitud, revisión y resultado
