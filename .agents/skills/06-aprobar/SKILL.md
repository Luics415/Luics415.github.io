# Skill: Aprobar (Portafolio)

- **Entrada:** `05-revisar/revision.yml`.
- **Acciones:**
  1. Revisar que todas las validaciones de build, responsive, enlaces y seguridad hayan pasado satisfactoriamente.
  2. Generar tabla ejecutiva de dictamen en español formal.
  3. Vincular enlaces directos a Pull Requests abiertos o Issues asociados.
  4. Emitir veredicto final: `Aprobado`, `Requiere Cambios` o `Bloqueado`.
- **Entregable:** Genera `06-aprobar/aprobacion.yml`.
