# Skill: Definir (Portafolio)

- **Entrada:** Revisa el estado del portafolio, el roadmap y la orden del usuario.
- **Acciones:**
  1. Redacta especificaciones precisas para nuevos casos de estudio, proyectos destacados o mejoras de interfaz.
  2. Define estructura de datos requerida en `portfolio-source/src/data/projects.ts` y contratos de props.
  3. Establece criterios de aceptación funcionales, visuales y de accesibilidad.
- **Entregable:** Genera el artefacto de fase `01-definir/definicion.yml` según `docs/FechaAgente/PLANTILLA_AUDITORIA.md`.
- **Restricción:** No muta código fuente en modo de auditoría automática.
