# Expedientes de Auditoría y Agentes

Este directorio almacena el historial de expedientes y artefactos producidos por las seis fases del orquestador maestro del portafolio.

## Estructura por Fecha

Cada ejecución genera un subdirectorio fechado `docs/FechaAgente/<AAAA-MM-DD>/` con la siguiente secuencia:

- `01-definir/definicion.yml`
- `02-planificar/plan.yml`
- `03-construir/construccion.yml`
- `04-verificar/verificacion.yml`
- `05-revisar/revision.yml`
- `06-aprobar/aprobacion.yml`
- `auditoria.md` (resumen ejecutivo de la ejecución)
